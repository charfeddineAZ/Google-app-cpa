# راب تونس — Tounsi Rap Studio

تطبيق أندرويد **محلّي أولاً** لصناعة أغاني الراب بالدارجة التونسية، موش مجرّد صفحة فيها برومبة. الاستوديو يربط الفكرة بالقاموس التونسي، يولّد مسودة قابلة للتعديل، وبعدها يعدّيها على خمس بوابات مراجعة قبل ما تتحفظ في مكتبة الأغاني.

> المشروع لا يدّعي أن أي مولّد آلي يضمن «تونسي 100%» وحده. لذلك التطبيق يبيّن مصدر الكلمات، نتيجة كل فحص، والكلمات اللي يلزمها مراجعة بشرية بدل ما يخبي الأخطاء.

## شنوة فيه التطبيق؟

- **الاستوديو:** عنوان، موضوع، ستايل، طاقة، وكلمات تونسية مختارة ثم زر توليد مسودة كاملة.
- **القاموس:** 50 مفردة تونسية مرتبة حسب النوع، مع المعنى، مثال الاستعمال والبدائل.
- **البرومبة:** البرومبة الحيّة تتحدّث حسب اختياراتك وتنجم تنسخها لأي نموذج ذكاء اصطناعي.
- **المكتبة:** أغاني تجريبية جاهزة، مسوداتك، بحث، فلاتر، مفضّلة، فتح وتعديل وحذف. المسودات تتحفظ محلّياً في `SharedPreferences`.
- **المصفاة:** خمس مراجعات محلية واضحة: القاموس، اللهجة، الفلو والقافية، الأصالة والسلامة، والقراءة النهائية.
- **بلا API وبلا إنترنت:** التوليد التجريبي والقاموس يخدموا محلياً، وما فما حتى مفتاح سرّي داخل الـ APK.

## البرومبة الكاملة

البرومبة موجودة داخل تبويب **البرومبة** وتتبدّل آلياً. هذا هو جوهرها:

```text
أنت كاتب راب تونسي ومدقّق لهجة تونسية. اكتب أغنية أصلية حول الموضوع المعطى.

1) استخرج الكلمات التونسية المناسبة من القاموس المرفق قبل الكتابة، واستعمل معانيها وأمثلتها.
2) اكتب بالدارجة التونسية 100%؛ لا فصحى، لا لهجات أخرى، لا فرنسية ولا إنقليزية داخل الكلمات.
3) إذا ما تعرفش تعبير تونسي، ما تخترعوش: اتركه أو اسأل.
4) ما تقلّد حتى فنان موجود وما تعاود حتى عبارة معروفة.
5) أخرج مقدّمة، لازمة، كوبليهين، لازمة وخاتمة قابلة للغناء.

بعد المسودة، نفّذ خمس مراجعات:
- راجع كل كلمة مقابل القاموس والسياق التونسي.
- احذف الفصحى والدخيل وصحّح التصريف التونسي.
- اختبر النطق، طول الأسطر، الفلو والقافية وتكرار اللازمة.
- افحص الأصالة والسلامة: لا تقليد، لا كراهية، لا تهديد ولا تحريض.
- اقرأ النص كمستمع تونسي، أصلح آخر زلّة، وأخرج تقريراً يذكر نسبة القاموس ونتيجة كل مراجعة.
```

البرومبة داخل التطبيق تزيد عليها العنوان، الموضوع، الستايل، الطاقة، الكلمات المختارة ومعانيها وأمثلتها، لذلك هي **مصدر واحد** بدل نسخ ولصق متفرّق.

## كيفاش تخدم المصفاة؟

كل أغنية تاخذ `QaReport` ظاهر للمستخدم:

1. **بوابة اللهجة:** نسبة الحروف العربية ومطابقة مفردات القاموس.
2. **بوابة طبيعية التونسي:** هل الكلمات المختارة مستعملة في سياق مفهوم؟
3. **بوابة الفلو والقافية:** هل فما بنية أغنية ولازمة وأسطر كافية؟
4. **بوابة الأصالة والسلامة:** تنويع الكلمات وكشف عبارات العنف/الكراهية الواضحة.
5. **المراجعة النهائية:** عنوان حاضر ونص طويل بما يكفي للحفظ.

المصفاة المحلية هي فحص مساعد، موش بديل على أذن كاتب تونسي. قبل النشر اسمع النص وراجع الكلمات بنفسك.

## البناء والتشغيل

التصدير الأصلي ما كانش فيه Gradle Wrapper. من جهاز فيه Android Studio أو Gradle:

```bash
gradle wrapper
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
```

الحد الأدنى Android 7.0 (API 24)، والهدف API 36. التطبيق يستعمل Kotlin + Jetpack Compose وواجهة RTL.

## هيكل المشروع

```text
app/src/main/java/com/example/
├── MainActivity.kt                 # التنقل وواجهة التطبيق
├── data/RapRepository.kt           # القاموس، البرومبة، التوليد المحلي والمصفاة
├── data/SongStore.kt               # حفظ المكتبة محلياً
├── model/RapModels.kt              # النماذج والحالات
├── viewmodel/RapStudioViewModel.kt # حالة الاستوديو والمكتبة
├── ui/screens/
│   ├── StudioScreen.kt             # الكتابة والتوليد والمراجعة
│   ├── LibraryScreen.kt            # مخزن الأغاني
│   ├── DictionaryScreen.kt         # القاموس التونسي
│   ├── PromptScreen.kt             # البرومبة الحيّة
│   └── Ui.kt                       # مكوّنات الواجهة المشتركة
└── ui/theme/                       # ألوان وتايبوغرافيا الواجهة
```

## إضافة موديل خارجي لاحقاً

`RapRepository.buildPrompt()` هو العقدة الوحيدة التي تصنع البرومبة، و`RapRepository.analyse()` هو الحاجز المحلي بعد التوليد. إذا أضفت Gemini أو أي API لاحقاً، ابعث له البرومبة من الـ ViewModel ثم مرّر الرد دائماً إلى `analyse()` قبل عرضه أو حفظه. لا تحطّ API key في الكود أو داخل Git.
